# Andrew Hospodarysko — Resume

A static, single-page resume published via GitHub Pages: https://ahospodarysko.github.io/andrew-page/

Used as a shareable link in job applications instead of a PDF.

## Structure

- `index.html` — resume content
- `styles.css` — page styling

## Updating

Edit `index.html` / `styles.css` and push to `main` — GitHub Pages redeploys automatically.
